  <h3>🔧 Infrastructure & Automation</h3>
  <p><strong>Multi-Runner CI/CD Strategy:</strong></p>
  <ul>
    <li>🏠 <strong>Local Runners (Primary):</strong> Self-hosted macOS runners for fast, local execution</li>
    <li>☁️ <strong>GitHub Actions (Fallback):</strong> Cloud-based runners for reliability and scalability</li>
    <li>⏱️ <strong>Smart Timeouts:</strong> 30-minute job limits with automatic failure detection</li>
    <li>📊 <strong>Comprehensive Logging:</strong> Detailed logs for all job executions and timeouts</li>
    <li>🎮 <strong>Manual Dispatch:</strong> Trigger workflows on-demand for any branch</li>
